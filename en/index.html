Applications

Timecode Stopwatch

Timecode Stopwatch is a professional timecode stopwatch application designed for video creators.

It supports tasks that require frame-based time measurement, including video editing, animation, filming, and storyboard production.

Features

  • 24 / 25 / 30 / 50 / 60 fps
  • NTSC Drop-Frame Timecode
  • LAP recording
  • Timecode-based time measurement
  • Japanese / English interface

Platform: Android

An iOS version is planned for a future release.
